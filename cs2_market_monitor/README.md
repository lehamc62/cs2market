# CS2 Market Monitor

Локальный мониторинг **★ Skeleton Knife | Doppler (Factory New), Phase 4** через CSFloat API. Приложение только читает историю завершённых продаж и текущие объявления. Средняя цена продажи за день и минимальная цена объявления — разные показатели.

## Запуск в Windows / PyCharm

1. Откройте корень проекта в PyCharm и выберите интерпретатор Python.
2. В терминале PyCharm установите зависимости: `python -m pip install -r requirements.txt`.
3. Задайте `CSFLOAT_API_KEY` в переменных окружения конфигурации запуска или в текущем сеансе PowerShell: `$env:CSFLOAT_API_KEY = Read-Host "CSFLOAT_API_KEY"`. Не сохраняйте ключ в файлах проекта.
4. Запустите в терминале: `python -m streamlit run app.py`. Откройте адрес, который покажет Streamlit.

При первом открытии интерфейс делает два GET-запроса к CSFloat. История кэшируется на час, объявления — на 5 минут. Кнопка «Обновить данные» очищает оба кэша и повторяет запросы. Выбор периода использует кэш. Для консольной проверки можно выполнить `python main.py`.

Показатель «Загружено объявлений» относится только к текущей выборке (запрашивается не более 20 записей). Разница между минимальным объявлением и последней дневной средней продаж показана в USD и процентах от средней продажи; это сравнение разных показателей. На графике цены можно переключить дневные значения и 7-дневный тренд, взвешенный по числу сделок. На длинных периодах график объёма по умолчанию суммирует продажи по календарным неделям. Время последнего успешного получения истории и объявлений показано отдельно.

Текущая неполная неделя выделяется на графике объёма. В таблице ссылка на объявление строится только при наличии его `id` в ответе API; если `id` отсутствует, ячейка остаётся пустой.

Интерфейс читает локальный каталог из `data/processed/` и предлагает последовательный выбор оружия, скина, фазы, состояния и версии. Характеристики и изображение берутся из каталога. Для CSFloat используется точное `market_hash_name` выбранного варианта и его `paint_index`, если он есть. История показывается только при однозначном рыночном имени в каталоге или для ранее проверенного Skeleton Doppler Phase 4 FN Normal. Если разные фазы имеют одинаковое имя, история остальных фаз скрыта до проверки фильтрации API; объявления остаются доступны с фильтром `paint_index` и проверкой этого поля в ответе. Параметры StatTrak, Souvenir и состояния отдельно не выдумываются: используется их полное имя из каталога.

Состояния перечисляются в стандартном порядке CS2 и только при наличии варианта в каталоге. Если у скина одна раскраска без фаз, селектор раскраски скрыт, но её `paint_index` сохраняется в выбранном варианте. Каталог загружается через `st.cache_resource`; повторный выбор состояния использует уже прочитанные CSV.

Без сети проверьте код командой `python -m unittest discover -s tests -v`. Тесты подменяют HTTP-запросы. Сохранённые CSV и исходный `csfloat_test.py` оставлены для сверки; интерфейс читает актуальные данные через `csfloat_client.py` и не перезаписывает CSV.
